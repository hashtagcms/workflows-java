#

HashtagCMS Workflows (Java)

Headless, server-driven workflow engine — Spring Boot.

API-only · no server-rendered UI

This service exposes a declarative workflow engine over a small REST API. A workflow is JSON config (validation → target → success/failure branches with a message, client directives, and data); the engine runs it, interpolates {{ }} tokens, negotiates directives down to what the calling client can render, logs the run, and returns { success, message, directives, data }. There is no HTML UI — this page is just a signpost to the live endpoints and the docs.
